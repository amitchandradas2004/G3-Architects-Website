# 🏗️ G3 Architects – Startup Landing Page

A modern and responsive startup landing page designed for an architecture company.  
This project focuses on clean UI design, structured layout, and responsive web development principles.

---

## 🚀 [Live Demo](https://amitchandradas2004.github.io/G3-Architects-Website/)

---

## 📌 Project Overview

**G3 Architects** is a professional landing page built to showcase an architecture firm’s brand, features, achievements, and sponsors.  
The website highlights company experience, services, statistics, and trusted partners in a clean and minimal layout.
